{{- /* YouTube 動画（Hugo 標準の youtube ショートコードを置き換える） 使い方：{{< youtube id="動画ID" title="動画の題名" >}} ページを開いた時点では YouTube に一切接続しない（Cookie を使う外部スクリプトを読み込まないため）。 - サムネイル画像は、ビルド時に YouTube から取得してこのサイトの画像として配信する - 再生ボタンを押したときに初めて、プライバシー強化モード（youtube-nocookie.com）のプレーヤーを読み込む（assets/js/youtube.js） - JavaScript が動かない環境では、YouTube の動画ページへの普通のリンクになる */ -}} {{- $id := .Get "id" | default (.Get 0) -}} {{- $title := .Get "title" | default "YouTube 動画" -}} {{- $thumb := "" -}} {{- with try (resources.GetRemote (printf "https://i.ytimg.com/vi/%s/hqdefault.jpg" $id)) -}} {{- with .Err -}} {{- warnf "YouTube のサムネイルを取得できませんでした（%s）: %s" $id . -}} {{- else with .Value -}} {{- $thumb = (.Fill "640x360 Center webp q78").RelPermalink -}} {{- end -}} {{- end -}}
